# encounter888 的文档

欢迎来到我的个人文档站。这里用来沉淀平时折腾出来的技术笔记和踩坑记录。

本站由 [Docsify](https://docsify.js.org) 驱动：**页面内容全部是 Markdown 文件，由浏览器实时渲染**，不需要任何构建步骤。往仓库里丢一个 `.md` 文件，它就自动变成一页。

> 搜索框在左上角，支持全文检索。左侧点击目录即可跳转，浏览器地址栏会自动变成 `#/路径` 形式，可以直接分享子页面链接。
